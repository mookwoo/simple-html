CSS Glassmorphism

CSS 
/* Create a glass effect */
.glass-card {
  background: rgba(255, 255, 255, 0.1);
  backdrop-filter: blur(20px);
  border-radius: 1rem;
  border: 1px solid rgba(255, 255, 255, 0.2);
  box-shadow: 0 8px 32px 0 rgba(0, 0, 0, 0.1);
}
The glassmorphism effect combines transparency, blur, and subtle borders to create a frosted glass appearance.

CSS Animation

CSS 
/* Smooth gradient animation */
@keyframes gradient {
  0% { background-position: 0% 50%; }
  50% { background-position: 100% 50%; }
  100% { background-position: 0% 50%; }
}

.animated-bg {
  animation: gradient 15s ease infinite;
}
CSS keyframes enable smooth animations. This creates a flowing gradient background that loops infinitely.

JavaScript DOM

JS 
// Select and modify elements
const card = document.querySelector('.card');

card.addEventListener('click', () => {
  card.classList.toggle('active');
  card.style.transform = 'scale(1.1)';
});
JavaScript brings interactivity to your pages. Use DOM manipulation to respond to user actions and update content dynamically.

Responsive Layout

CSS 
/* Mobile-first grid system */
.grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 2rem;
}

@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}
CSS Grid and media queries make responsive layouts simple. Start mobile-first, then add breakpoints for larger screens.

Fetch API

JS 
// Get data from an API
async function getData() {
  const response = await fetch('/api/data');
  const data = await response.json();
  
  console.log(data);
  return data;
}
The Fetch API provides a modern way to make HTTP requests. Use async/await for clean, readable asynchronous code.

How the Creator Effect Works

Gradient Text Effect

CSS 
/* Animated rainbow gradient text */
.creator-name {
  background: linear-gradient(
    45deg,
    #ff6b6b, #4ecdc4, #45b7d1,
    #96ceb4, #ffeaa7, #ff6b6b
  );
  background-size: 300% 300%;
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  animation: rainbowFlow 6s ease infinite;
}
Uses background-clip to apply an animated gradient to text. The gradient shifts position to create a flowing rainbow effect.

Pulsing Glow Animation

CSS 
/* Add glowing pulse effect */
@keyframes textGlow {
  0%, 100% { 
    filter: drop-shadow(0 0 20px 
      rgba(255, 255, 255, 0.3));
    transform: scale(1);
  }
  50% { 
    filter: drop-shadow(0 0 30px 
      rgba(255, 255, 255, 0.5));
    transform: scale(1.02);
  }
}
Combines drop-shadow filter with scale transform to create a breathing, glowing effect that pulses continuously.
